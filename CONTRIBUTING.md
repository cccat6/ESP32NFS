# Contributing

Contributions to storage adapters, ESP32 integration, documentation and examples are welcome.

1. Open an issue describing the intended behavior or submit a focused pull request.
2. Follow the existing C++ style and `.clang-format` configuration.
3. Update user documentation and examples alongside public API changes.
4. Run Arduino Lint and compile the examples for the ESP32 target families used by CI.
5. Describe the behavior and validation in the pull request.

The repository contains the distributable library, application examples, user documentation and release automation. Keep local device credentials, experimental firmware, development utilities, measurements and build products in an external development workspace.

The code is licensed under MIT. Preserve third-party attribution when contributing externally sourced code.
